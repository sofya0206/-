# LUMO Analytics

Внутренняя платформа сквозной аналитики для YouTube, CRM, отдела продаж, финансов, продукта и Telegram-автоматизаций.

## Что работает

- карточки клиентов с анкетой, UTM, роликом, менеджером, статусом, заметками и выручкой;
- ручное создание и CSV-импорт заявок;
- защищённый webhook заявок с автоматическим назначением менеджера;
- воронка, конверсии, скорость ответа, аналитика возраста и дохода;
- расходы по статьям и P&L из сохранённых операций и оплат CRM;
- ручное обновление NPS, учеников, кейсов и других продуктовых метрик;
- напоминания менеджерам, журнал событий и Telegram-сводка;
- синхронизация роликов и просмотров через YouTube Data API после добавления ключей.

## Запуск

```bash
npm install
npm run dev
```

Проверка обеих production-сборок:

```bash
npm run test
VERCEL=1 npm run build
```

## Внешние подключения

Для реальных интеграций нужны защищённые переменные среды: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `YOUTUBE_API_KEY`, `YOUTUBE_CHANNEL_ID` и `LEAD_WEBHOOK_SECRET`. Прирост подписчиков за период требует отдельного YouTube Analytics OAuth-доступа; обычного Data API key недостаточно.
